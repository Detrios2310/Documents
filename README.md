# Документы

Android-приложение для хранения всех документов в одном месте.

## Возможности

- Категории (личные, авто, медицина, финансы и др.), поиск по названию и заметке
- Несколько страниц у одного документа, порядок страниц можно менять
- Фото из галереи или прямо с камеры
- Обрезка сразу под формат документа: карта/права, разворот паспорта, A4 (книжный и альбомный), свободная рамка или без обрезки
- Срок действия с подсветкой, когда он скоро истекает
- Вход по PIN, графическому ключу или отпечатку (по желанию)
- Поделиться фото документа
- Всё хранится только на телефоне

## Как получить APK

1. Отправьте изменения в ветку `main`.
2. Откройте вкладку **Actions** в репозитории, выберите последний запуск «Build Android APK».
3. Внизу страницы запуска в разделе **Artifacts** скачайте `documents-apk`, внутри лежит `.apk`.

Сборку можно запустить и вручную: Actions → Build Android APK → Run workflow.

## Стек

React Native, Expo SDK 58, TypeScript. Сборка идёт на GitHub Actions: `expo prebuild` и Gradle, без expo.dev.
